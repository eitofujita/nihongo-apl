# Nihongo AI

英語・ロシア語話者向けの日本語学習アプリ。Next.js App Router / TypeScript strict / React / Tailwind CSS / next-intl / Zod で実装しています。

## 現在の段階

初期検証の追加サービス費は**月額0円、Cloudflareは無料枠限定**です。公開先はCloudflare Workersを選び、OpenNextによるビルド・ローカル実行を準備しました。アカウント登録と最初のWrangler認証は完了し、公開用権限の追加認証とWorkers Free表示確認を待っています。外部公開はまだです。Supabase Free・AI固定解説を継続し、有料プランや課金AIの有効化は行いません。無料枠に収まらなければ停止して報告します。[Cloudflareの手順と検証範囲](docs/cloudflare.md)、[費用計画](docs/cost-plan.md)を参照してください。

**JLPT N5〜N3の教材（文法261項目・単語3,527語）・学習フロー・苦手分析に加え、Supabase認証とアカウント別クラウド保存のアプリ側コードを実装しています。SupabaseのURL・公開キー設定とAuthサービスへの疎通、ユーザーによるSQL適用後のテーブル・取得関数の存在と匿名アクセス拒否は確認済みです。実登録・メール確認・ログイン、レッスン結果と再ログイン後の履歴保持、同じPCの別ブラウザまたはプライベート環境での同期は本人の報告・画像で確認済みです。** ゲスト学習は外部サービスの契約やAPIキーなしで試せます。

実装済み：

- 英語 `/en`・ロシア語 `/ru` のUI、言語切り替え、ロケール別メタデータとhreflang
- ダッシュボード、ランディング、レッスン一覧・絞り込み・検索
- 文法20項目・語彙10テーマの計30レッスン。100語の学習表、練習100問（文法60問・単語40問）、四択・穴埋め・英露の解説
- 説明・例文または読み付き単語表を確認してから練習を開始
- N5の10問チェックと結果に基づく開始レッスンの推薦。JLPTの公式判定ではありません
- 初回ホームから診断、または第1課の説明へ直接進める。学習後は推薦レッスンや期限のある復習へ案内
- 最新の回答から苦手項目を集計し、復習期限・苦手項目・未完了の順で次の学習を推薦
- ホームの情報を次の学習・進捗・コース／復習へのリンクに整理。広告カード・装飾・重複案内を削減
- 履歴、正答率、学習時間、連続学習日数、練習した語彙数
- Supabase設定後に使える登録・ログイン・メール確認・ログアウト・パスワード再設定（英露対応）
- 登録後は専用のメール確認画面へ移動。確認リンクで認証後にホームへ進み、元のタブもサーバーでログインを確認して自動移動
- アカウント別の履歴・設定・復習保存、RLS、DB側の固定正解による採点、重複再送防止
- ゲストは従来どおりブラウザ保存。ゲストとアカウントの履歴を自動的に混ぜない設計
- 間違えた問題の復習キュー：10分後、正解後は1日・3日・7日後
- 言語に依存しない教材ID・進捗保存、日次目標設定、確認ダイアログ付きリセット
- AIチューターの説明サンプル、料金案内（支払いは無効）
- 文を作る練習（試作）：英露の訳を見て日本語の語句を並べ替える。N5〜N3の例文から1回10文（[詳細](docs/curriculum.md#文を作る練習試作)）
- N5漢字103字の書き取り練習（試作）：なぞる→グリッドのみ→意味と読みだけの3段階。書き順・位置・向きをブラウザ内で判定し、進捗は端末内のみ保存。漢字を含む単語・例文の表示と、自分で選んだ漢字のテスト（`/kanji/test`）つき（[詳細](docs/curriculum.md#漢字の書き取り試作n5のみ)）
- PC・スマートフォン向けUI、キーボード操作、フォントのローカル配信
- Zodによる教材・入力・保存データの検証、破損データのフォールバック
- VitestとPlaywrightのテスト

**未実装・未検証：** 実Supabaseでの別アカウント間のデータ分離・実機の端末間同期、一般ユーザーへのメール配信、診断の教育的妥当性の検証、教師による教材校閲、実LLM接続とサーバーでの利用量制限、有料権限・決済、Cloudflareでの実公開・無料枠内のCPU負荷確認。

この段階は販売可能な完成版ではありません。教材は独自の固定データです。型・正解整合性などはテストしていますが、独立した日本語教師による校閲済みとは表示しません。教材範囲と校閲項目は[docs/curriculum.md](docs/curriculum.md)に記載しています。AI画面は固定文の表示で、LLMにリクエストしません。接続設定がない場合は登録・ログインを有効化せず、ゲスト学習を案内します。

## 起動

必要環境：**Node.js 22.22.2以上、npm 10以上**。Python環境は使用しません。

```bash
# nvmを使用している場合
nvm install
nvm use

npm ci
cp .env.example .env.local
npm run dev
```

- 英語：<http://localhost:3000/en>
- ロシア語：<http://localhost:3000/ru>
- 紹介ページ：<http://localhost:3000/en/welcome>

`/` はnext-intlがブラウザの言語・ロケールCookieに応じて `/en` または `/ru` へ誘導します。

この作業環境では、システムのNode.js 18に代えて一時領域へNode.js 22を用意しました。同じ環境でそのまま起動する場合：

```bash
PATH=/tmp/nihongo-tools/node_modules/node/bin:$PATH npm run dev
```

`/tmp` は一時領域なので、継続開発ではnvm等でNode.js 22を用意してください。

## コマンド

```bash
npm run typecheck  # TypeScript strict
npm run lint       # ESLint（anyをエラーとして検出）
npm test           # Vitest
npm run test:live   # 起動中のアプリと実Supabaseへ、変更を伴わない接続確認
npm run check      # 上記3つを順番に実行
npm run build      # 本番ビルド
npm start          # ビルド後の本番サーバー
npm run build:cloudflare # Workers用ビルド（ローカル検証時はURLを8787に設定）
npm run check:cloudflare # アップロードしない設定・容量検査
npm run preview:cloudflare # ビルド済みWorkerをローカルで起動
npm run test:e2e:cloudflare # Workers上のPC・モバイルテスト
npm run kanji -- <KanjiVGのkanji/> # 漢字索引と書き順・使用例データを再生成（引数なしなら使用例だけ更新）
npm run sentences  # 文を作る練習の問題を教材から再生成（npm run content のあと）

npx playwright install chromium
npm run test:e2e   # ChromiumでPC・モバイルを確認
```

Linuxでブラウザ用のシステムライブラリが不足する場合は、環境管理者にPlaywrightの依存ライブラリ導入を依頼してください。E2Eテストはポート3000の開発サーバーを再利用し、なければ自動起動します。本番サーバーに対して検証する場合も、ポート3000で起動してから同じテストを実行できます。別ポートを使う場合は `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3100 npm run test:e2e` のように指定します。

## 設定

Cloudflare対応では、型チェック・Lint・通常テスト98件、WorkersローカルでのPC／モバイルテスト43件、非変更型の実接続テスト16件が成功しました。OpenNextビルド・Wrangler dry-runも成功しています。実公開と無料枠のCPU負荷は未確認です。詳細は[Cloudflare検証記録](docs/cloudflare.md)を参照してください。

| 変数 | 用途 | 初期値 |

| `NEXT_PUBLIC_APP_URL` | 公開URL。canonical・sitemap・認証リダイレクト・CSRF許可originの基点 | `http://localhost:3000` |
| `PLUS_PRICE_JPY` | Plusの表示価格。サーバーで整数範囲を検証 | `980` |

`.env.local` はGit対象外です。`NEXT_PUBLIC_*` はブラウザに公開されるため、秘密鍵を設定しないでください。価格を変更したときは開発サーバーを再起動、公開後は再デプロイしてください。

## データと運用上の境界

- ゲストの保存先は`localStorage`の`nihongo-ai:progress:v1`。個人情報・メール・APIキーをlocalStorageへ保存しません。認証CookieはHttpOnlyでサーバー側管理します。
- ゲストの学習結果は端末・ブラウザ単位です。ログイン後はSupabaseの本人の記録を使います。どちらも表示言語を切り替えても同じ進捗を使います。クラウド結果をゲストキーに保存せず、ログアウト後に別ユーザーのデータを表示しないようにします。
- 既存の6レッスン・18問のIDと保存キーを維持しています。旧バージョンの3問の学習結果も読み込めます。
- 単語表は100語を扱い、基本練習では40語を出題します。「練習した単語数」は実際に回答した語の重複を除いた数です。
- 診断は既存の固定問題から10問を選びます。診断や復習はレッスンの完了数を増やしません。
- 復習期限の表示は30秒ごとに更新します。
- 記録は最大1,000セッションまでで、超えたら古い記録を削除します。表示集計も保持中の記録を対象とします。
- 学習時間は問題の操作開始から完了までで、1回最大60分です。ページを閉じる前に未完了の結果は保存されません。
- localStorageは利用者が変更できます。**認証・支払い状態・有料権限の判定には使用しません。** 現在は無料プランのみで、課金状態を作る処理はありません。
- UIはReactの標準エスケープを使用し、教材や質問をHTMLとして挿入しません。
- ローカルのサンプル操作には外部APIコストが発生しません。認証・進捗APIには同一Origin検証・Zod・短期レート制限を実装済みです。採点とRLS、200セッション／日の上限はDB側でも実施します。実AIの利用量予約・予算管理は今後の実装です。
- 読み上げは端末の日本語音声が利用可能な場合のみ動作します。音声がない場合はその旨を表示します。
- プライバシー・利用規約・販売者表示の本番文書は、事業者情報と提供地域が決まってから用意します。

2. **Phase 3の残作業：** 実装した20文法／100語／100問を英露両方で日本語教師が校閲。DB側採点は実装済みで、実Supabaseでも動作確認する。診断の教育的妥当性を検証する。
3. **Phase 4の残作業：** 実装済みのクラウド履歴と復習処理を実プロジェクトで確認。端末間同期と複数タブのアカウント切替を確認。
4. **Phase 5：** 問題・正解をサーバーで取得し、ロケール別AI質問、用途制限、トークン・日次利用・予算上限を実装。
5. **Phase 6：** 事業所在地・利用資格に合う決済サービスを選定。検証済みWebhookからのみ有料権限を発行。
6. **Phase 7：** ステージングで認証/RLS/API障害を確認し、事業者情報・利用規約を整備してCloudflareで商用公開。

外部プロジェクト作成・有料契約・本番課金はこの実装では行っていません。

認証・クラウド保存の接続手順、テーブル権限、メール設定、実環境での確認項目は[supabase/README.md](supabase/README.md)に記載しています。SQL適用とローカルの認証・同期は確認済みですが、実アカウント間のデータ分離と公開先での認証確認は残っています。

## Cloudflare公開準備

実装・テスト・アカウント作成からの手順は[docs/cloudflare.md](docs/cloudflare.md)に記載しています。公開URL未設定のまま`deploy:cloudflare`を実行すると停止します。秘密情報や開発用の`.env.local`はアップロードしません。無料枠での実測と認証確認が必要で、ローカル検証の成功だけで本番運用可能とは判定しません。
