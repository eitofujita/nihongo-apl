# 初回診断から学習・復習への導線

## 初めて学習する人

学習履歴が0件の場合、ホームの主な操作は「N5の開始チェック」です。10問の結果から開始レッスンを提案します。完全な初心者は「第1課から始める」を選び、診断を飛ばして説明と例文から学べます。診断への小さなリンクを重複表示しません。

英語・ロシア語で同じ画面と教材IDを使います。診断は短い文法チェックで、JLPT合否やN5全範囲の習得を判定するものではありません。教材の独立した教師による校閲は引き続き必要です。

## 診断またはレッスンを終えた人

診断や学習の記録がある場合、ホームは復習期限、苦手項目、未学習レッスンの優先順で次の行動を提案します。初回診断を強制しません。結果画面も復習が必要な場合は復習ページへ、それ以外は提案されたレッスンの説明ページへ移動します。

学習済みの人の履歴は既存の保存形式のまま扱い、表示言語を変更しても同じ進捗を利用します。今回の導線変更にDBマイグレーションは不要です。

## 検証

- 英語・ロシア語のホームで、診断と第1課の双方へ移動できる。
- ホーム→診断→提案レッスン→ホームへ戻っても診断結果が保持される。
- レッスン完了後に次の未学習レッスンへ進める。
- 復習期限のある問題が残っている場合、レッスン結果から復習ページへ進める。
- PC・スマートフォンで横スクロールがなく、ロシア語の長い表示が収まる。
