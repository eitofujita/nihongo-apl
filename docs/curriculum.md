# N5教材と校閲の状態

文法20項目、語彙10テーマ・100語、基本練習100問（文法60問・単語40問）を提供します。各レッスンは説明、例文または単語表、練習、結果の順です。文法は各3問、語彙は各4問です。語彙レッスンには10語の読みと英露の意味を掲載し、そのうち4語を基本練習で扱います。

## 品質の境界

- 固定の独自教材であり、LLMの回答を正解として採用する仕組みはありません。
- 単語練習の選択肢と説明の組み立ては、固定の語彙データから決定的に行います。学習者がアクセスするたびに外部AIで生成しません。
- IDの一意性、100語・100問の件数、四択の数と重複、正解の存在、英露の必須データ、問題の重複、語彙参照の整合性を自動テストします。
- 文法的・教育的な正しさをこれらのテストだけで保証できません。日本語教師および英露の校閲者による独立した確認は未実施です。
- 文脈を補う翻訳を付けています。移動先の「へ／に」のような両方が正しい選択肢を同じ問題に並べず、解説では他の許容形にも触れています。
- 20項目はMVPの範囲です。JLPT N5の全範囲を網羅する、または公式に認定されたリストとは表示しません。

## 校閲時の確認項目

1. 日本語の自然さ、読み、学習者の段階に合う語彙・漢字。
2. 四択の他の選択肢が同じ文脈・意味で正解にならないか。
3. 穴埋めの許容解、異表記、丁寧さの扱い。
4. 英語とロシア語の意味・時制・否定・指示範囲が日本語と一致するか。
5. 解説が問題文と正解に対応しているか。
6. 単語の複数の読み・意味を文脈に応じて説明しているか。
7. 10問チェックの難易度と推薦結果が学習者に適切か。

## 学習開始チェックと推薦

診断は基本文法の固定10問を使う目安です。誤答から苦手項目を選び、全問正解の場合は後半の練習を提案します。JLPTの合否やN4以上の能力は判定しません。

通常のホーム画面では、期限が来た復習、最新回答に誤りが残る項目、未完了レッスンの順に提案します。訂正できた問題は苦手集計から外れます。間隔反復の対象は、その後も予定された間隔で出題します。
